# Repository rules

The working rules for this repository are installed centrally from `hz-claude-config` (cloud sessions: the cloud environment's setup script; local sessions: the `hz-rules` plugin). They are not copied into this repository — do not add copies.

If the "Global Working Rules" are not in your context — neither loaded as a CLAUDE.md nor injected at session start — stop before any work and tell me: "Central rules not loaded in this session."

Repository-specific files: `FEATURES.md` and `WORKING_RECORD.md`.
